# folders.js

Manage this desktop’s persistent shared roots via authenticated loopback. The shell supplies a
native folder chooser; headless nodes allow an absolute path. Show counts, partial scan warnings,
rescan and stop-sharing controls. File references stay on the hosting desktop regardless of Home.

The Folders view lists shared and imported roots on this desktop, including empty or unavailable shares. Remove opens a confirmation naming the selected root and acts on its source ID. Library refresh updates the list. Remote catalogue folders remain browseable filters.

The browser derives immediate children and counts from logical paths. Breadcrumbs link to any ancestor.
