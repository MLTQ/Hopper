# Desktop podcast discovery

The Browse dialog requests charts or submitted searches from one directory and scopes categories to that provider. A request counter prevents slower responses from overwriting the latest search. Each row shows a thumbnail, show and publisher. Subscribe queues the selected URL for the chosen desktop.

Selecting this desktop for Podcast Index offers a local credentials form. The secret is sent only to the authenticated loopback configuration endpoint. Closing or replacing the form discards its contents.
