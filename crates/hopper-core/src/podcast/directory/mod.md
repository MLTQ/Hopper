# Podcast directory

Both shells post a provider, a search term, a provider-specific category ID and an optional destination desktop. A blank term browses a chart. The Apple adapter runs on the requesting device. Podcast Index requests go to the selected desktop over the authenticated pairing when necessary.

Each page carries its provider’s categories and at most 40 distinct listings in provider order. The listing URL is accepted by Home subscription intake. Titles are bounded, and cover and show links allow HTTP and HTTPS only. The query contains no provider credentials.
